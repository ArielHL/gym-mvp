# Guía de instalación — Versión Preview (Android)

Esta guía explica cómo instalar en tu teléfono Android la **versión preview** de la app CaliFit (Gym Mobile MVP). La versión preview es una build de prueba con las funciones más recientes que aún no están disponibles en la versión final.

---

## Requisitos

- Teléfono con **Android 7.0 o superior**.
- Al menos **300 MB de espacio libre** en el teléfono.
- El archivo de instalación (`.apk`) que te fue enviado por WhatsApp, email o un enlace de descarga.
- Conexión a internet para descargar el archivo y usar la app.

---

## Instalación paso a paso

### Paso 1 — Descarga el archivo `.apk`

1. Abre el enlace, el mensaje de WhatsApp o el email donde se te compartió la versión preview.
2. Toca el archivo **`gym-mobile-mvp-preview.apk`** (o similar).
3. Confirma la descarga y espera a que termine. Puedes ver el progreso en la barra de notificaciones.

### Paso 2 — Permite la instalación desde fuentes desconocidas

Android bloquea por seguridad la instalación de apps que no vienen de Google Play. Debes permitirla para la app desde la que abrirás el archivo (WhatsApp, navegador o el gestor de archivos).

**En Android 8 a Android 12:**

1. Ve a **Ajustes → Seguridad** (o **Ajustes → Aplicaciones**).
2. Busca **Instalar apps desconocidas**.
3. Selecciona la app desde la que descargaste el archivo (por ejemplo, WhatsApp o Chrome).
4. Activa **Permitir desde esta fuente** (o **Instalar apps desconocidas**).

**En Android 13 o superior:**

- Al tocar el archivo `.apk`, Android mostrará una ventana preguntando: *"¿Permitir que WhatsApp (o Chrome) instale aplicaciones?"*.
- Toca **Permitir** y la instalación continuará.

### Paso 3 — Instala el archivo

1. Abre el archivo `.apk` descargado desde **WhatsApp**, el **navegador** o el **gestor de archivos** (por ejemplo, la carpeta *Descargas*).
2. Lee los **permisos** que solicita la app y toca **Instalar**.
3. Espera a que termine la instalación (suele tardar unos segundos).
4. Toca **Listo** para salir, o **Abrir** para usar la app de inmediato.

### Paso 4 — Maneja la advertencia de Google Play Protect

Al instalar, Google puede mostrar el mensaje: *"Play Protect no reconoce al desarrollador de esta aplicación"*.

1. Toca **Más detalles**.
2. Toca **Instalar de todos modos**.
3. Confirma con **Aceptar** si se te pregunta de nuevo.

### Paso 5 — Abre la app

1. Busca el ícono de **CaliFit / Gym Mobile** en tu pantalla de inicio o en el cajón de aplicaciones.
2. Toca el ícono para abrirla.
3. Inicia sesión con tu cuenta o crea una nueva desde la pantalla de bienvenida.

---

## Primer uso

- Si ya tienes una cuenta, inicia sesión con tu email o con Google.
- Si es tu primera vez, toca **Registrarse** y sigue los pasos.
- La app pedirá permiso para enviar **notificaciones**; tócalo para no perderte los recordatorios de tus clases.

---

## Solución de problemas

| Problema | Solución |
|---|---|
| La descarga no inicia | Revisa la conexión a internet y el espacio libre. Pide de nuevo el archivo a quien te lo envió. |
| "No se pudo abrir el archivo" | Verifica que el archivo termine en `.apk`. Si lo abres desde un email, descárgalo primero y luego ábrelo desde el gestor de archivos. |
| Play Protect bloquea la instalación | Toca **Más detalles → Instalar de todos modos** (ver Paso 4). |
| "No se puede abrir el archivo" o "Hubo un problema al analizar el paquete" | El archivo está incompleto o dañado. Descárgalo nuevamente (asegúrate de que termine de descargarse por completo). |
| "El paquete parece ser inválido" | Es posible que el archivo se haya corrompido al transferirlo. Pide un nuevo enlace de descarga o reenvíalo desde el origen. |
| "No se pudo instalar" sin más detalles | Desinstala cualquier versión anterior de la app (ver siguiente fila) y vuelve a intentar. |
| Ya hay una versión anterior instalada | Ve a **Ajustes → Aplicaciones → CaliFit → Desinstalar**, y luego instala el nuevo APK. Algunas versiones preview no se pueden instalar encima de otra. |
| La app se abre pero se cierra | Apaga y enciende el teléfono, y vuelve a abrirla. Si persiste, desinstálala e instala la versión más reciente del APK. |
| Quiero la versión nueva | Cada build preview es nueva; pide a quien te la compartió el **último** archivo `.apk` e instálalo siguiendo estos pasos. |

---

## Nota importante

- La versión **preview es solo para pruebas**: puede contener errores, cambios de diseño o funciones incompletas.
- No se actualiza sola desde Google Play. Debes instalar manualmente cada nueva versión que recibas.
- Si tienes problemas de datos (clases, reservas) o de inicio de sesión, confirma que estés usando la **versión más reciente** del APK.
